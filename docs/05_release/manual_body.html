음성인식 장비 CER/WER 시험 프로그램

CER App 사용 매뉴얼

음성(.wav)을 음성인식 서버로 보내 받은 결과를 정답 전사(.txt)와 비교해 CER·WER을 계산합니다. 브라우저 화면에서 실행하고, 수천~수만 건도 중간 결과를 보며 시험할 수 있습니다.

시작하기입력 파일화면 사용시험 옵션 중지·이어서비교 규칙결과 파일문제 해결

1. 시작하기

  1. 프로그램 실행

    PowerShell 또는 명령 프롬프트에서 프로젝트 폴더로 이동해 실행합니다.

    cd "D:\2. Team Source\CER App"
python -m app.main

    브라우저가 자동으로 열립니다. 열리지 않으면 주소창에 http://127.0.0.1:8765를 입력하세요. 포트가 겹치면 --port 8800을 붙입니다. 종료는 터미널에서 Ctrl+C입니다.

  2. 서버 설정과 연결 확인

    ① 설정·실행 탭에서 서버 주소, 포트, API 키, 모델을 입력하고 연결 확인을 누릅니다. ● 정상이 나오면 서버가 응답한 것입니다. API 키는 한 번 저장하면 다음 실행부터 입력하지 않아도 됩니다.

  3. 입력 폴더 지정과 파일 검색

    음성 폴더와 정답 전사 폴더를 입력하고 파일 검색을 누르면 시험할 수 있는 건수와 예상 소요 시간이 표시됩니다.

  4. 옵션 선택 후 실행

    시험 종류에 맞게 옵션을 고르고 실행을 누르면 ② 실시간 결과 탭으로 이동해 진행 상황이 갱신됩니다.

준비물Python 3.14와 websocket-client 패키지가 필요합니다. 패키지는 pip install websocket-client로 설치합니다.

2. 입력 파일 준비

구분형식조건
음성이름.wav8kHz, mono, 16bit PCM. 다른 형식은 경고 후 제외됩니다.
정답 전사이름.txtUTF-8. 음성과 같은 기본 이름이어야 합니다.
폴더 위치음성 폴더, 전사 폴더각각 따로 지정할 수 있습니다. 전사 폴더를 비우면 음성 폴더와 같은 위치를 사용합니다.
탐색 깊이하위 폴더 한 단계지정한 폴더와 그 아래 한 단계 폴더까지만 찾습니다.

정답 전사를 찾는 순서

음성 폴더 기준 같은 상대 경로의 이름.txt를 전사 폴더에서 먼저 찾고, 없으면 전사 폴더 안에서 같은 이름을 찾습니다. 둘 다 없으면 그 파일은 경고와 함께 제외됩니다.

파일 이름 규칙이름 규칙은 없습니다. 이름이 _rx, _tx로 끝나면 결과 화면에서 화자(rx/tx)별 평균을 따로 보여줍니다.

3. 화면 사용

탭무엇을 하나
① 설정·실행서버·모델·입력 폴더·시험 옵션을 정하고 실행, 일시정지, 중지합니다.
② 실시간 결과누적 CER/WER, 최근 구간 CER, 응답 속도, 진행률과 남은 예상 시간, CER 변화 그래프를 1초마다 갱신해 보여줍니다.
③ 파일별 결과파일별 CER/WER을 스크롤하며 봅니다. 파일명 검색, 상태 필터, CER 최소값, 열 머리글 클릭 정렬을 지원합니다. 행을 누르면 ④로 이동합니다.
④ 상세선택한 파일의 정답과 인식 결과를 나란히 보여주고 치환·삽입·삭제를 색으로 표시합니다.
⑤ 리포트시험 전체 결과를 detail.csv, summary.json, summary.txt로 받습니다.

화면 아래쪽 상태줄에는 모든 탭에서 완료·실패 건수, 누적 CER, 응답 속도 평균, 남은 시간이 표시됩니다. 브라우저의 뒤로가기 버튼으로 이전 탭에 돌아갈 수 있습니다.

오류율이 높은 파일 찾기

③에서 CER 열 머리글을 눌러 내림차순으로 정렬하면 가장 나쁜 파일이 맨 위에 옵니다. 행을 눌러 ④에서 어디가 틀렸는지 확인합니다.

시험 중 CER 변화 보기

② 그래프의 누적 CER은 전체가 수렴하는 모양을, 최근 구간 CER은 최근 500건의 품질 변화를 보여줍니다.

4. 시험 옵션

옵션설명권장
문장 단위 시험평균 7초 내외의 문장 음성 수천~수만 건을 시험할 때 켭니다. 끄면 5분 이상 장시간 통화 파일로 봅니다.데이터에 맞게 선택
응답 속도 측정문장 단위 시험에서만 동작합니다. 음성 입력을 마친 시점부터 최종 인식 결과가 완료될 때까지의 시간을 파일별로 재고 평균을 냅니다. 30초 이상 파일은 속도 집계에서 제외됩니다(CER은 계산).속도를 볼 때만 켬
동시 접속동시에 서버로 보내는 파일 수입니다.속도 측정 1 / CER만 4
실시간 페이싱 해제음성을 실제 재생 속도보다 빠르게 보냅니다. 켜면 응답 속도 측정은 꺼지고 경고가 표시됩니다.CER만 볼 때
이어서 하기이전 시험에서 완료된 파일을 건너뛰고 이어갑니다. 시험을 시작하기 전에 체크해야 합니다.장시간 시험 시 켬
소요 시간실시간 페이싱을 지키므로 음성 길이만큼 시간이 걸립니다. 7초 음성 1만 건을 동시 접속 1로 시험하면 약 19시간, 동시 접속 4면 약 5시간입니다.

5. 중지와 이어서 하기

  1. 중지

    ① 탭의 중지 버튼을 누르고 확인하면 즉시 멈추고, 그때까지 완료된 파일만으로 CER/WER을 산정해 리포트를 저장합니다. ② 탭 상단에 "중지됨 — 전체 N건 중 완료 M건 기준"이 표시됩니다.

  2. 일시정지

    잠시 멈췄다가 재개로 이어갑니다. 서버 연결은 파일 단위라 새 파일부터 멈춥니다.

  3. 이어서 하기

    이어서 하기를 체크하고 실행하면 data\results\last_run에 쌓인 완료 건은 다시 보내지 않습니다. 진행 중이던 파일은 실패가 아니라 미완료로 남아 다시 시험됩니다.

중간 저장100건마다 live_snapshot.json이 저장되고 완료 건은 state.jsonl에 즉시 기록되므로, 창을 닫거나 PC가 꺼져도 완료된 결과는 남습니다.

6. 비교 규칙 (정규화)

정답과 인식 결과 양쪽에 같은 규칙을 적용한 뒤 비교합니다.

규칙처리예
빈 줄제거하고 한 문장으로 이어 붙임여러 줄 전사 → 한 줄
전사 태그영문 한 글자 + 슬래시는 무시n/, b/ 제거
특수문자문장부호와 기호는 무시, . ! ? ~ 제거
추임새목록의 단어는 비교에서 제외음, 어, 아, 네, 예 등
숫자 표기아라비아 숫자를 한글 독음으로 통일5 → 오
병기 표기(A)/(B)는 둘 중 하나만 맞아도 정답(5살)/(다섯 살)
병기 표기 예

정답이 저는 (5살)/(다섯 살) 입니다일 때 인식 결과 저는 5살 입니다와 저는 다섯 살 입니다 모두 오류 0으로 계산됩니다. 정답 길이(N)에는 맞는 쪽 하나만 들어갑니다.

계산 방식

CER은 공백을 뺀 글자 단위, WER은 공백 기준 어절 단위로 (치환+삽입+삭제) ÷ 정답 길이입니다. 전체 평균은 파일별 평균이 아니라 오류 합 ÷ 정답 길이 합입니다.

7. 결과 파일

결과는 data\results\<실행시각>\ 폴더에 저장됩니다. 이어서 하기를 쓰면 last_run 폴더에 저장됩니다.

파일내용
<이름>_result.txt음성인식 결과 원문. 입력 <이름>.wav, 정답 <이름>.txt와 같은 기본 이름입니다.
detail.csv파일별 CER/WER, S/I/D/N, 길이, 응답 속도, 비고(엑셀에서 열람).
summary.txt사람이 읽는 요약. 중지한 경우 "중지됨"이 표기됩니다.
summary.json전체·화자별 CER/WER, CER 분포, 응답 속도 통계, 실행 설정(API 키 제외).
<이름>_messages.jsonl서버가 보낸 응답 원본. 인식 결과가 이상할 때 확인합니다.
state.jsonl완료·실패 기록. 이어서 하기에 사용됩니다.

8. 문제 해결

증상원인조치
연결 확인이 실패서버 주소·포트 오류, 서버 꺼짐, 네트워크 문제주소와 포트를 다시 확인하고 같은 망에서 접속하는지 확인합니다.
실행 시 "서버 거부(401)"API 키가 틀렸거나 인증 방식 불일치키를 다시 입력합니다. 프로그램은 X-API-Key 헤더 방식으로 접속합니다.
"정답 TXT 없음, 제외"같은 이름의 .txt를 찾지 못함음성·전사 폴더 경로와 파일 이름을 확인합니다.
"8kHz/mono/PCM16 필요"WAV 형식이 다름8kHz, mono, 16bit PCM으로 변환합니다.
"UTF-8이 아닌 텍스트 파일"전사 파일이 다른 인코딩UTF-8로 저장해 다시 시험합니다.
실행 버튼이 눌리지 않음이미 시험이 진행 중② 탭에서 상태를 확인하고 끝나거나 중지한 뒤 다시 실행합니다.
화면이 이전 버전 같음브라우저 캐시Ctrl+F5로 새로고침합니다.
API 키 관리API 키는 config.local.json에만 저장되고 화면과 리포트에는 가려서 표시됩니다. 이 파일은 저장소에 올리지 말고 다른 사람과 공유하지 마세요.
