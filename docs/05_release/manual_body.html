음성인식 장비 CER/WER 시험 프로그램

CER App 사용 매뉴얼

음성인식 서버가 설치된 현장의 폐쇄망 PC에서 음성(.wav)을 서버로 보내 받은 결과를 정답 전사(.txt)와 비교해 CER·WER을 계산합니다. 인터넷과 별도 설치 없이 압축 파일을 풀어 사용하며, 수천~수만 건도 중간 결과를 보며 시험할 수 있습니다.

설치처음 시험하기입력 파일화면 사용 시험 옵션중지·이어서비교 규칙결과 파일 문제 해결관리

1. 설치 (인터넷·관리자 권한 불필요)

설치 프로그램이 없습니다. 압축 파일 하나를 풀고 start.bat을 실행하면 끝입니다.

항목조건
PCWindows 10 또는 11 (64비트)
브라우저Microsoft Edge 또는 Chrome (Windows에 기본 포함)
인터넷필요 없음 (폐쇄망에서 동작)
Python 설치필요 없음 (패키지에 포함)
네트워크이 PC에서 음성인식 서버 주소와 포트로 접속할 수 있어야 함
디스크프로그램 약 30MB + 시험 데이터와 결과를 저장할 공간
  1. 압축 파일을 PC로 옮기기

    USB 등으로 CER_App_portable.zip을 현장 PC에 복사합니다.

  2. 압축 풀기

    파일을 마우스 오른쪽 버튼으로 눌러 모두 추출을 선택하고, 쓰기 가능한 폴더(예: D:\CER_App)에 풉니다. C:\Program Files 같은 시스템 폴더는 피하세요. 결과 파일을 쓸 수 없을 수 있습니다.

  3. start.bat 실행

    풀린 폴더의 start.bat을 더블클릭합니다. 검은 창이 열리고 잠시 후 브라우저에 프로그램 화면이 나타납니다.

    브라우저가 열리지 않으면 주소창에 http://127.0.0.1:8765를 입력합니다.

  4. 검은 창은 닫지 않기

    검은 창(터미널)이 프로그램 본체입니다. 시험하는 동안에는 열어 두고, 끝낸 뒤 창을 닫으면 프로그램이 종료됩니다.

Windows 보호 화면이 나타나면"Windows의 PC 보호" 창이 뜨면 추가 정보를 누르고 실행을 선택합니다. 보안 프로그램이 막는 경우에는 현장 보안 담당자에게 python\python.exe 실행 허용을 요청하세요.

2. 처음 시험하기

  1. 서버 설정과 연결 확인

    ① 설정·실행 탭에서 서버 주소, 포트, API 키, 모델을 입력하고 연결 확인을 누릅니다. ● 정상이 나오면 서버가 응답한 것입니다. 서버 주소와 키는 서버 관리자에게 받습니다. 한 번 저장하면 이 PC에서는 다시 입력하지 않아도 됩니다.

  2. 입력 폴더 지정과 파일 검색

    음성 폴더와 정답 전사 폴더를 입력하고 파일 검색을 누르면 시험할 수 있는 건수와 예상 소요 시간이 표시됩니다. 연습용으로는 프로그램 폴더의 data\input에 파일을 넣어 사용하면 됩니다.

  3. 옵션 선택 후 실행

    시험 종류에 맞게 옵션을 고르고 실행을 누르면 ② 실시간 결과 탭으로 이동해 진행 상황이 갱신됩니다.

  4. 결과 확인과 저장

    끝나면 ⑤ 리포트 탭에서 detail.csv, summary.txt를 받거나 결과 폴더 열기를 누릅니다.

처음에는 소량으로처음 사용하는 PC에서는 파일 3~5건으로 먼저 연결과 결과를 확인한 뒤 전체 시험을 시작하세요.

3. 입력 파일 준비

구분형식조건
음성이름.wav8kHz, mono, 16bit PCM. 다른 형식은 경고 후 제외됩니다.
정답 전사이름.txtUTF-8. 음성과 같은 기본 이름이어야 합니다.
폴더 위치음성 폴더, 전사 폴더각각 따로 지정할 수 있습니다. 경로를 직접 입력하거나 폴더 선택 버튼으로 폴더 트리를 열어 고를 수 있습니다(▸를 눌러 하위 폴더를 펼치고, 폴더를 눌러 선택하면 안의 .wav/.txt 개수가 표시됩니다. 입력칸에 이미 경로가 있으면 그 위치까지 자동으로 펼쳐집니다). 전사 폴더를 비우면 음성 폴더와 같은 위치를 사용합니다.
탐색 깊이하위 폴더 한 단계지정한 폴더와 그 아래 한 단계 폴더까지만 찾습니다.

정답 전사를 찾는 순서

음성 폴더 기준 같은 상대 경로의 이름.txt를 전사 폴더에서 먼저 찾고, 없으면 전사 폴더 안에서 같은 이름을 찾습니다. 둘 다 없으면 그 파일은 경고와 함께 제외됩니다.

파일 이름 규칙이름 규칙은 없습니다. 이름이 _rx, _tx로 끝나면 결과 화면에서 화자(rx/tx)별 평균을 따로 보여줍니다.

4. 화면 사용

탭무엇을 하나
① 설정·실행서버·모델·입력 폴더·시험 옵션을 정하고 실행, 일시정지, 중지합니다.
② 실시간 결과누적 CER/WER, 최근 구간 CER, 응답 속도, 진행률과 남은 예상 시간, CER 변화 그래프를 1초마다 갱신해 보여줍니다. 아래쪽 "CER 분포"에는 구간별 파일 수가 0%:61건 ~5%:16건 ~10%:11건 10%+:1건처럼 표시됩니다.
③ 파일별 결과파일별 CER/WER을 스크롤하며 봅니다. 파일명 검색, 상태 필터, CER 최소값, 열 머리글 클릭 정렬을 지원합니다. 행을 누르면 ④로 이동합니다.
④ 상세선택한 파일의 정답 원문과, 비교에 쓰인 정답·인식 결과를 나란히 보여주고 치환·삽입·삭제를 색으로 표시합니다. 숫자는 원래 표기(예: 17살)로 보이고, (A)/(B) 병기는 인식 결과와 맞는 쪽이 표시됩니다. 색의 의미: 주황 = 치환(같은 자리 단어가 다르게 인식), 초록 = 삽입(정답에 없는 단어가 추가, 인식 결과 쪽), 빨강 취소선 = 삭제(정답에 있는 단어가 빠짐, 정답 쪽), 색 없음 = 일치. 화면 아래쪽에 같은 범례가 표시됩니다(단어 단위 비교).
⑤ 리포트시험 전체 결과를 detail.csv, summary.json, summary.txt로 받습니다. 아래 "요약 미리보기"에서 결과를 한눈에 볼 수 있습니다(아래 읽는 법 참고).
⑥ 시험결과 요약검증 결과를 제출·캡처하기 위한 한 장짜리 요약입니다. 음성파일 갯수, 음성 합계시간, 시험 소요시간(동시 접속 수 포함), 누적 CER/WER, 응답속도 평균, 완료/전체 건수와 1-CER, 1-WER 막대 그래프를 보여줍니다. [텍스트로 복사] 버튼으로 같은 내용을 글자로 복사할 수 있습니다. 시험 중에는 "진행 중 (중간 결과)"로 표시됩니다.

화면 아래쪽 상태줄에는 모든 탭에서 완료·실패 건수, 누적 CER, 응답 속도 평균, 남은 시간이 표시됩니다. 브라우저의 뒤로가기 버튼으로 이전 탭에 돌아갈 수 있습니다.

오류율이 높은 파일 찾기

③에서 CER 열 머리글을 눌러 내림차순으로 정렬하면 가장 나쁜 파일이 맨 위에 옵니다. 행을 눌러 ④에서 어디가 틀렸는지 확인합니다.

시험 중 CER 변화 보기

② 그래프의 누적 CER은 전체가 수렴하는 모양을, 최근 구간 CER은 최근 500건의 품질 변화를 보여줍니다.

⑤ 요약 미리보기 읽는 법

영역보는 방법
상단 배지시험 완료 또는 중지됨 (완료된 결과 기준). 실행 시각, 시험 모드, 모델, 동시 접속 수, 소요 시간이 함께 표시됩니다.
CER / WER 카드전체 글자 오류율과 어절 오류율입니다. 낮을수록 좋습니다.
오류 내역틀린 글자 수와 치환·삽입·삭제 내역, 비교한 정답 글자 수입니다.
파일완료 / 전체 건수, 실패 건수(중지한 경우 미실행 건수).
화자별파일 이름이 _rx, _tx로 끝날 때 화자별 CER/WER을 따로 보여줍니다.
응답 속도문장 단위 시험에서 평균, 중앙값, p95, 최대와 측정·제외 건수를 보여줍니다.
파일별 CER 분포75.9%(22건) ████ CER:0% 형식입니다. 왼쪽은 전체 파일 중 비율과 건수, 오른쪽은 그 파일들의 CER 구간(0%, ~5%, ~10%, 10%+)입니다. 10% 이상 구간은 빨간색입니다.
텍스트로 보기summary.txt 원문입니다. 보고서에 그대로 붙여 넣을 수 있습니다.

5. 시험 옵션

옵션설명권장
문장 단위 시험평균 7초 내외의 문장 음성 수천~수만 건을 시험할 때 켭니다. 끄면 5분 이상 장시간 통화 파일로 봅니다.데이터에 맞게 선택
응답 속도 측정문장 단위 시험에서만 동작합니다. 음성 입력을 마친 시점부터 최종 인식 결과가 완료될 때까지의 시간을 파일별로 재고 평균을 냅니다. 30초 이상 파일은 속도 집계에서 제외됩니다(CER은 계산).속도를 볼 때만 켬
동시 접속동시에 서버로 보내는 파일 수입니다. 시험 중에도 ② 실시간 결과 탭 위쪽에서 바꿀 수 있고, 새로 시작하는 파일부터 적용되며 남은 시간이 다시 계산됩니다.속도 측정 1 / CER만 4
실시간 페이싱 해제음성을 실제 재생 속도보다 빠르게 보냅니다. 켜면 응답 속도 측정은 꺼지고 경고가 표시됩니다.CER만 볼 때
이어서 하기이전 시험에서 완료된 파일을 건너뛰고 이어갑니다. 시험을 시작하기 전에 체크해야 합니다.장시간 시험 시 켬
소요 시간실시간 페이싱을 지키므로 음성 길이만큼 시간이 걸립니다. 7초 음성 1만 건을 동시 접속 1로 시험하면 약 19시간, 동시 접속 4면 약 5시간입니다.

6. 중지와 이어서 하기

  1. 중지

    ① 탭의 중지 버튼을 누르고 확인하면 즉시 멈추고, 그때까지 완료된 파일만으로 CER/WER을 산정해 리포트를 저장합니다. 중지하는 동안 "중지하는 중..."이 표시되고, 끝나면 "중지됨 — 완료된 N건의 결과로 집계했습니다"로 바뀝니다. ② 탭 상단에도 "중지됨 — 전체 N건 중 완료 M건 기준" 안내가 표시됩니다.

  2. 일시정지

    잠시 멈췄다가 재개로 이어갑니다. 새 파일 전송만 멈추고, 이미 전송 중이던 파일은 끝까지 처리되므로 정지 직후 완료 건수가 1~2건 더 오를 수 있습니다. 일시정지 중에는 경과 시간이 멈추고 남은 시간은 "일시정지 중"과 함께 고정되며, 재개하면 멈춘 값에서 이어서 계산됩니다. 정지한 시간은 소요 시간에 포함되지 않습니다.

  3. 이어서 하기

    이어서 하기를 체크하고 실행하면, 결과 저장 폴더 안에서 같은 음성 폴더로 실행한 가장 최근 시험 폴더에 이어서 저장하며 이미 완료된 파일은 다시 보내지 않습니다. 어느 폴더에 이어가는지는 체크박스 아래에 이어서 하기: … "20261015_1030" 폴더에 이어서 저장합니다처럼 표시됩니다. 이어갈 시험이 없으면 새 시험 폴더가 만들어집니다. 진행 중이던 파일은 실패가 아니라 미완료로 남아 다시 시험됩니다.

중간 저장100건마다 live_snapshot.json이 저장되고 완료 건은 state.jsonl에 즉시 기록되므로, 창을 닫거나 PC가 꺼져도 완료된 결과는 남습니다.

7. 비교 규칙 (정규화)

정답과 인식 결과 양쪽에 같은 규칙을 적용한 뒤 비교합니다.

규칙처리예
빈 줄제거하고 한 문장으로 이어 붙임여러 줄 전사 → 한 줄
전사 태그영문 한 글자 + 슬래시는 무시n/, b/ 제거
특수문자문장부호와 기호는 무시, . ! ? ~ 제거
추임새목록의 단어는 비교에서 제외음, 어, 아, 네, 예 등
숫자 표기아라비아 숫자를 한글 독음으로 통일5 → 오
병기 표기(A)/(B)는 둘 중 하나만 맞아도 정답(5살)/(다섯 살)
병기 표기 예

정답이 저는 (5살)/(다섯 살) 입니다일 때 인식 결과 저는 5살 입니다와 저는 다섯 살 입니다 모두 오류 0으로 계산됩니다. 정답 길이(N)에는 맞는 쪽 하나만 들어갑니다. (17살)/(열 일곱 살)이랑처럼 뒤에 조사가 공백 없이 붙어 있으면 각 대안에 붙여서 17살이랑 / 열 일곱 살이랑으로 비교합니다. "열 네 살"의 "네"는 숫자이므로 추임새로 지우지 않습니다.

계산 방식

CER은 공백을 뺀 글자 단위, WER은 공백 기준 어절 단위로 (치환+삽입+삭제) ÷ 정답 길이입니다. 전체 평균은 파일별 평균이 아니라 오류 합 ÷ 정답 길이 합입니다.

8. 결과 파일

① 탭의 결과 저장 폴더(기본 data esults)를 지정하면, 시험을 시작할 때마다 그 안에 년월일시분 하위 폴더가 자동으로 만들어져 결과가 저장됩니다. 예: 20261015_1030은 2026년 10월 15일 10시 30분에 시작한 시험입니다. 같은 분에 다시 시작하면 초(20261015_103045)가 붙어 구분됩니다. 시험이 끝나면 ① 탭 메시지와 ② 탭에 실제 저장 위치가 표시됩니다.

파일내용
<이름>_result.txt음성인식 결과 원문. 입력 <이름>.wav, 정답 <이름>.txt와 같은 기본 이름입니다.
detail.csv파일별 CER/WER, S/I/D/N, 길이, 응답 속도, 비고(엑셀에서 열람).
summary.txt사람이 읽는 요약(CER/WER, 화자별, 응답 속도, 파일별 CER 분포). 중지한 경우 "중지됨"이 표기됩니다.
summary.json전체·화자별 CER/WER, CER 분포, 응답 속도 통계, 실행 설정(API 키 제외).
<이름>_messages.jsonl서버가 보낸 응답 원본. 인식 결과가 이상할 때 확인합니다.
state.jsonl완료·실패 기록. 이어서 하기에 사용됩니다.

이전 시험 결과 다시 보기

프로그램을 껐다 켜도 결과 폴더만 있으면 이전 시험의 파일별 결과와 정답·인식 결과 비교를 다시 볼 수 있습니다. 서버 연결은 필요 없고, 읽기 전용이라 결과 파일은 바뀌지 않습니다.

  1. 이전 시험 결과 열기

    ① 설정·실행 탭 아래쪽 "이전 시험 결과 열기"에는 결과 저장 폴더 안의 시험 목록이 년월일시분 폴더 이름, 실행 시각, 완료 건수, CER과 함께 최근 것부터 표시됩니다. 원하는 시험을 누르면 바로 열립니다. 목록에 없으면 폴더 선택으로 시험 폴더를 고르고 열기를 누릅니다. 결과 저장 폴더 자체를 골라도 안에 시험이 하나면 자동으로 열리고, 여러 개면 목록에서 고르게 됩니다.

  2. 확인

    화면 위쪽에 주황색 "이전 시험 보기 (읽기 전용)" 안내가 표시됩니다. ③ 파일별 결과, ④ 상세, ⑤ 리포트, ⑥ 시험결과 요약이 그 시험의 값으로 바뀝니다.

  3. 닫기

    안내 오른쪽의 닫기를 누르면 이전 시험 보기가 끝나고 새 시험을 실행할 수 있습니다. 시험이 진행 중일 때는 열 수 없습니다.

정답 원본 파일이 없을 때④ 상세에서 "정답 원본 파일을 찾을 수 없습니다"가 표시되고 인식 결과만 보입니다. 정답 파일을 옮겼다면 ① 탭에서 정답 폴더를 지정한 뒤 다시 열면 비교가 표시됩니다.

9. 문제 해결

증상원인조치
start.bat 검은 창이 바로 닫힘압축을 풀지 않고 실행했거나 보안 프로그램이 차단zip 안에서 실행하지 말고 모두 추출 후 실행합니다. 계속되면 보안 담당자에게 문의합니다.
"사용 중인 포트" 오류프로그램이 이미 실행 중이거나 같은 포트를 다른 프로그램이 사용열려 있는 검은 창을 닫고 다시 실행합니다. 계속되면 명령 프롬프트에서 start.bat --port 8800으로 실행하고 http://127.0.0.1:8800으로 접속합니다.
브라우저에 화면이 안 나옴자동 열기 실패주소창에 http://127.0.0.1:8765를 직접 입력합니다.
연결 확인이 실패서버 주소·포트 오류, 서버 꺼짐, 네트워크 문제주소와 포트를 다시 확인하고 같은 망에서 접속하는지 확인합니다.
실행 시 "서버 거부(401)"API 키가 틀렸거나 인증 방식 불일치키를 다시 입력합니다. 프로그램은 X-API-Key 헤더 방식으로 접속합니다.
"정답 TXT 없음, 제외"같은 이름의 .txt를 찾지 못함음성·전사 폴더 경로와 파일 이름을 확인합니다.
"8kHz/mono/PCM16 필요"WAV 형식이 다름8kHz, mono, 16bit PCM으로 변환합니다.
"UTF-8이 아닌 텍스트 파일"전사 파일이 다른 인코딩UTF-8로 저장해 다시 시험합니다.
"중지하는 중..."이 오래 표시됨전송 중이던 파일을 마무리하는 중보통 수 초 안에 "중지됨"으로 바뀝니다. 계속되면 ② 탭 상단에 "중지됨" 안내가 나오는지 확인하고, 안 바뀌면 검은 창을 닫았다가 다시 실행합니다(완료된 결과는 이어서 하기로 이어집니다).
폴더 선택 창이 안 열림다른 PC에서 접속했거나 화면이 이전 버전이 프로그램을 실행한 PC의 브라우저에서 접속해야 합니다. Ctrl+F5로 새로고침합니다. 경로를 직접 입력해도 됩니다.
실행 버튼이 눌리지 않음이미 시험이 진행 중② 탭에서 상태를 확인하고 끝나거나 중지한 뒤 다시 실행합니다.
결과 폴더에 파일이 안 생김쓰기 권한이 없는 위치에 풂프로그램을 쓰기 가능한 폴더(예: D:\CER_App)에 다시 풀거나, 결과 저장 폴더를 다른 곳으로 지정합니다.
화면이 이전 버전 같음브라우저 캐시Ctrl+F5로 새로고침합니다.

10. 관리 (업데이트·삭제·키 보관)

작업방법
새 버전으로 교체새 zip을 다른 폴더에 풀고, 이전 폴더의 config.local.json(서버·키 설정)과 data\results를 복사해 옮깁니다.
삭제프로그램 폴더를 삭제하면 끝입니다. 레지스트리나 다른 위치에는 남는 것이 없습니다.
다른 PC로 이전폴더를 통째로 복사하면 됩니다. API 키가 들어 있으므로 config.local.json은 필요한 경우에만 옮깁니다.
여러 사람이 사용한 PC를 함께 쓰면 결과가 같은 폴더에 쌓입니다. 구분이 필요하면 화면에서 결과 저장 폴더를 사람별로 지정합니다.
API 키 관리API 키는 config.local.json에만 저장되고 화면과 리포트에는 가려서 표시됩니다. 이 파일은 USB나 메신저로 다른 사람에게 보내지 마세요.
