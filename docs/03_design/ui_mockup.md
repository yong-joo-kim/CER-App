## 상세 화면
행을 더블클릭하면 정답(`<name>.txt`)과 인식 결과(`<name>_result.txt`)를 좌우로 비교하고, 치환·삽입·삭제를 색으로 표시한다.

```
┌─ 상세: 20241119164515_1028_rx.wav / model_v2 ─────────────────────────────────────┐
│ 정답(정규화 후)                     │ 인식 결과(정규화 후)                        │
│ 그러면 동구청 보건소로 연결해 달라  │ 그러면 동구청 [보건소를→보건소로] 연결해 달라│
│ ...                                 │ ...   (치환=주황, 삽입=초록, 삭제=빨강)     │
└──────────────────────────────────────────────────────────────────────────────────┘
```

## 개정 시안 2: 진행 중 CER 변화 표시 (FR-17)

- 창을 닫거나 비정상 종료돼도 `live_snapshot.json`/`state.jsonl`로 이어서 하기 및 중간 결과 확인 가능
